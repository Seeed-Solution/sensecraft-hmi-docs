## Introduction

**[SenseCraft HMI](https://sensecraft.seeed.cc/hmi)** is Seeed Studio's cloud-based UI design platform for ePaper display devices. It helps you pair compatible hardware, create visual pages, connect live data, and deploy updates without writing code.

Whether you are onboarding your first device or building a more advanced dashboard, this documentation hub helps you move from setup to design and deployment quickly.

**Core Capabilities:**
- No-code drag-and-drop page design
- Device pairing and remote management
- Live data integration and widgets
- AI-assisted image and layout generation
- One-click deployment to supported hardware
