#### Introducción

La placa controladora ePaper EE03, basada en **XIAO ESP32-S3 Plus**, es compatible con una **pantalla ePaper de 10.3 pulgadas y alta velocidad de refresco**. Incorpora un conector JST de 2.0 mm para batería con interruptor de alimentación, circuito integrado de carga y dispone de un botón de reset y tres botones de usuario. Es muy adecuada para proyectos ePaper de bajo consumo, como marcos de fotos digitales y paneles informativos.

#### Características

- **Incluye XIAO ESP32-S3 Plus integrado:** funciona inmediatamente al conectarse a una pantalla ePaper compatible.
- **Compatibilidad dedicada con pantalla ePaper monocroma de 10.3":** diseñada específicamente para pantallas ePaper monocromas de 10.3" con refresco rápido, garantizando una puesta en marcha sencilla y un funcionamiento estable.
- **Refresco de alta velocidad habilitado:** el control de temporización T-CON integrado proporciona una conducción precisa de alta velocidad, mientras que el SHT40 integrado ofrece detección de temperatura en tiempo real para compensación de forma de onda.
- **Conector BAT con interruptor:** facilita la conexión de batería e integra un interruptor para una gestión energética eficiente.
- **Botones fáciles de usar:** incluye 1 botón de reset y 3 botones programables por el usuario para acelerar el desarrollo de proyectos y personalizar funciones.

#### Introducción

El **TRMNL 7.5" (OG) DIY Kit** es un kit ePaper de hardware abierto con una pantalla monocroma de 7.5 pulgadas. SenseCraft HMI puede instalarse en este kit como alternativa sin código al firmware predeterminado de TRMNL.

#### Características

- **Compatibilidad TRMNL BYOD**: kit oficial para construir un dispositivo TRMNL 7.5" OG, con soporte para más de 375 plugins y 8 diseños sin código (por ejemplo Calendar, Shopify, GitHub)

- **Diseño energéticamente eficiente**: batería de 2000 mAh con hasta 3 meses de funcionamiento en modo deep sleep (actualización cada 6 horas)
- **Compatibilidad con doble ecosistema**: compatible con Home Assistant (a través de ESPHome) y Arduino IDE para desarrollo personalizado
- **Carcasas de código abierto**: disponibles en Printables y Thingiverse para facilitar la personalización
